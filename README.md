# Display Options Mod
Wish you could set a specific resolution?\
Need VSync for a smoother experience?\
This mod provides the solution!

Integration with [BBModMenu](https://thunderstore.io/c/beton-brutal/p/Beton_Bros/BBModMenu/)
makes it very easy to adjust settings.

### Features
- VSync
- Fullscreen\*
- Resolution options\*
- Keybind for resolution snap (default: `F11`)

\*Click `Apply` for changes to take effect.

### Resolution Sizes
There are 18 resolution sizes to choose from.\
Still can't find your size? We got you covered!\
Select `Custom Resolution` and set your own size.

Click `Apply` button when finished.

## Install
This mod is used with [MelonLoader](https://github.com/LavaGang/MelonLoader).\
Mod dependency: [BBModMenu](https://github.com/MiaouZart/BBModMenu)\
You may also get this on [Thunderstore](https://thunderstore.io/c/beton-brutal/p/Beton_Bros/DisplayOptions/).
